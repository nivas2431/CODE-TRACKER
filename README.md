# Code Tracker

Code Tracker is a Chrome extension that helps organize coding problems from multiple platforms such as LeetCode, CodeChef, and others.

## Features
- Track coding problems from different platforms
- Organize solved and unsolved problems
- Easy review for better learning and productivity

## Technologies Used
- JavaScript
- HTML
- CSS
- Chrome Extension APIs

## How to Use
1. Install the extension in Chrome
2. Open any coding platform
3. Track and manage your problems easily
